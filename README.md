# Professional Training Credentials & Portfolio of Evidence

 Designed as a platform to showcase Simphiwe Tebogo Morare's learning track record.

## 🛠️ Architecture & Technology Stack

- **HTML5**: Semantic markup with full WCAG 2.1 accessibility compliance.
- **CSS3**: Pure CSS custom properties (variables), modern CSS Grid, Flexbox, glassmorphism UI, and dark/light mode toggle.
- **Vanilla JavaScript (ES6+)**: Zero framework dependencies. Dynamic client-side rendering from structured JS arrays, live filtering, and modal dialog management.
